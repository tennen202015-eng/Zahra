# زهرة — تطبيق أندرويد

تطبيق لتتبع الدورة الشهرية والحمل والأمومة، مبني بـ Capacitor. كل البيانات محفوظة على الجوال، والإذن الوحيد اللي التطبيق بيطلبه من المستخدمة هو **الإشعارات**.

## محتويات المشروع

| الملف | الوظيفة |
|---|---|
| `src/app.html` | التطبيق نفسه (نفس النسخة اللي على الويب مع الإشعارات) |
| `capacitor.config.json` | اسم التطبيق ومعرّفه `com.zahra.tracker` |
| `android-res/` | أيقونة التطبيق، أيقونة الإشعار، شاشة البداية |
| `scripts/build-web.js` | ينسخ التطبيق والخطوط وjsPDF علشان يشتغل من غير إنترنت |
| `scripts/patch-android.js` | يركّب الأيقونات ويحصر الصلاحيات في الإشعارات فقط |
| `.github/workflows/android.yml` | يبني ملف APK تلقائياً على GitHub |

## الطريقة الأولى: بناء APK على GitHub (من غير ما تسطّبي حاجة)

1. اعملي حساب على [github.com](https://github.com) لو مش عندك.
2. اضغطي **New repository**، سمّيه مثلاً `zahra-app`، واختاري **Private**، وبعدين **Create repository**.
3. اضغطي **uploading an existing file**، واسحبي كل ملفات المشروع وفولداته.
   - فولدر `.github` مخفي في بعض الأجهزة. لو مارفعش، اعملي **Add file > Create new file**، واكتبي الاسم `.github/workflows/android.yml`، والصقي محتوى الملف.
4. اضغطي **Commit changes**.
5. افتحي تبويب **Actions**، هتلاقي **Build Android APK** شغال. البناء بياخد حوالي ٥-٨ دقايق.
6. لما يخلص، افتحيه وانزلي لـ **Artifacts** ونزّلي `zahra-apk`، وجواه `app-debug.apk`.
7. انقلي الملف للجوال وافتحيه. هيطلب منك السماح بالتسطيب من مصادر غير معروفة، اسمحي بيها مرة واحدة.

## الطريقة التانية: على الكمبيوتر بـ Android Studio

لازم يكون عندك Node.js 22 وAndroid Studio وJDK 21.

```bash
npm install
npm run build:web
npm run android:init
npx cap sync android
npx cap open android
```

ومن Android Studio: **Build > Build APK(s)**.

## الإشعارات

من **المزيد > الإعدادات > الإشعارات**، اضغطي «فعّلي الإشعارات» ووافقي على طلب الإذن. وبعدها تقدري تختاري:

- **الدورة:** قبلها بيومين ويوم موعدها، وبداية الخصوبة ويوم التبويض في وضع «أحاول الحمل»، ولو اتأخرت ٣ أيام.
- **يومياً:** الأدوية في الوقت اللي تحدديه، والماء ٤ مرات، وتذكير اليوميات.
- **الحمل:** بداية كل أسبوع جديد، والمواعيد قبلها بيوم وقبلها بساعتين، وعدّ الركلات من الأسبوع ٢٨.
- **الأمومة:** التطعيمات قبل موعدها بـ٣ أيام، وتذكير الرضعة الجاية.
- **رمضان:** تذكير بأيام القضاء قبله بأسبوع.
- **الخصوصية:** «إخفاء محتوى الإشعارات» بيخلي الإشعار يظهر بكلمة «تذكير» بس.

الإشعارات بتتجهز على الجوال نفسه من غير إنترنت، وبتتحدث تلقائياً كل ما تسجلي حاجة جديدة.

## الصلاحيات

- **الإشعارات:** الإذن الوحيد اللي بيظهر للمستخدمة.
- **ممنوعة صراحةً في الملف:** الكاميرا، والميكروفون، والموقع، والصور، والملفات، وجهات الاتصال.
- **حفظ التقرير والنسخة الاحتياطية:** بيتم من قائمة المشاركة بتاعة أندرويد، ومش محتاج أي صلاحية.
- **الإنترنت:** صلاحية تلقائية في أندرويد، مابتظهرش للمستخدمة. التطبيق مش بيبعت أي بيانات، والمساعدة الذكية مقفولة في النسخة دي.

## تسجيل الدخول بجوجل والنسخ على Drive

التطبيق بيطلب صلاحية واحدة بس: مساحة مخفية خاصة بالتطبيق جوه Drive بتاع المستخدمة (`drive.appdata`)، ومعاها الإيميل علشان يظهر في الإعدادات. مش بيشوف أي ملفات تانية في Drive.

لازم مشروع Google Cloud علشان تسجيل الدخول يشتغل:

1. افتحي [console.cloud.google.com](https://console.cloud.google.com) واعملي مشروع جديد اسمه `Zahra`.
2. من **APIs & Services › Library** فعّلي **Google Drive API**.
3. من **Google Auth Platform**:
   - **Branding:** اسم التطبيق «زهرة» وإيميل الدعم.
   - **Audience:** اختاري External. وطول ما التطبيق في وضع Testing، ضيفي الإيميلات اللي هتجرّب في **Test users**.
4. من **Clients › Create client** اختاري **Android**، واكتبي:
   - **Package name:** `com.zahra.tracker`
   - **SHA-1:** `CF:E4:FF:C4:90:56:60:A2:23:55:1F:83:CB:6D:3F:0B:A7:90:CB:A3`
5. خلاص، مش محتاجين نحط أي مفتاح في الكود.

لما ننشر على Google Play، هنضيف عميل Android تاني ببصمة SHA-1 بتاعة توقيع المتجر.

## النشر على Google Play لاحقاً

ملف `app-debug.apk` مناسب للتجربة والتوزيع المباشر. للنشر على المتجر محتاجين:

1. ملف توقيع (keystore).
2. بناء نسخة `release` بصيغة AAB.
3. سياسة خصوصية وصفحة المتجر.
